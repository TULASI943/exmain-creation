## Case Study 6: Examination Question Difficulty and Performance Analysis

### Problem Statement
Develop a Python program to compare student answer strings against an answer key, calculate question-wise success rates, identify frequently missed questions, and classify question performance.

### Objectives
- Compare student answers with the answer key.
- Calculate student-wise scores.
- Calculate question-wise success rates.
- Identify frequently missed questions.
- Classify question difficulty.
- Generate a performance report.

### Assumptions
- Total students: 5.
- Total questions: 5.
- Each question carries 1 mark.
- Correct answer receives 1 mark.
- Incorrect or blank answer receives 0 marks.

### Difficulty Classification
- 80% to 100%: Easy.
- 50% to 79%: Moderate.
- Below 50%: Difficult.

### Algorithm
1. Initialize the answer key.
2. Accept student answers.
3. Compare answers with the answer key.
4. Calculate student-wise scores.
5. Calculate question-wise correct answers.
6. Calculate success rates.
7. Identify frequently missed questions.
8. Classify question difficulty.
9. Display the final analysis report.
10. Stop.

### Python Concepts Used
- Variables
- Lists
- For loops
- If-elif-else statements
- Nested loops
- Arithmetic operators
- Membership operators
- Input and output functions

### Test Cases
1. All correct answers – 5/5.
2. One incorrect answer – 4/5.
3. Two incorrect answers – 3/5.
4. Three incorrect answers – 2/5.
5. Blank answers – Counted as incorrect.

### Expected Output
- Student-wise scores.
- Question-wise correct answers.
- Missed answers.
- Question success rates.
- Difficulty classification.
- Frequently missed questions.
- Answer key.

### Conclusion
The program successfully analyzes examination performance, identifies difficult questions, calculates success rates, and provides useful information about student performance using basic Python programming concepts.
